Key Prompts

"Create the foundational files and basic structure for a blank-page job tracking website using Flask, Python, HTML, and CSS."

"When implementing the job application filtering feature, I encountered an error that prevented the results from displaying correctly. Can you review my code, identify the cause, and help me fix it?"

"Can you create a function that allows users to switch the website's language between English and Spanish?"

What Worked Well

AI-generated starter files provided a good foundation for the project.

Excellent at explaining errors and helping debug issues.

Successfully helped create a function for switching between multiple website languages.

Provided useful UI design ideas and suggestions for improving the website's appearance.

What I Modified

Modified variable names and references to match the SQL database structure.

Adjusted UI colors, styling, and visual elements to fit the desired design.

Refined AI-generated code after testing to improve readability and maintain cleaner code.

Lessons Learned

Always verify AI-generated code and test it before implementation and actual usage.

AI suggestions sometimes require adjustments to fit the existing project structure.

Asking AI to explain its reasoning and proposed changes helps improve understanding of code additions and development plans.

Keeping track of AI-suggested changes makes it easier to understand and manage project modifications.
